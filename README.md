# Task 2: Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis on the Iris dataset using Python, Pandas, Matplotlib, and Seaborn to identify patterns, relationships, and feature distributions.

## Tools Used
- Python
- Pandas
- Matplotlib / Seaborn

## Approach & Outcome
- Loaded and inspected dataset summary statistics using `.describe()`.
- Created 5 distinct visualizations (Histogram, Boxplot, Scatter Plot, Heatmap, Pairplot).
- Documented key insights and answered core analytical questions directly within the notebook.
